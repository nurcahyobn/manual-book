<Note>
  Data ini bersifat sementara dan dapat berubah sebelum nilai akhir disahkan oleh fakultas.
</Note>

## Cara Penggunaan

1. Klik menu **DNS Mahasiswa** di sidebar kiri.
2. Sistem akan menampilkan daftar nilai sementara untuk semester aktif.
3. Periksa kolom nilai (Yudisium dan Bobot) untuk memastikan semua mata kuliah sudah terisi.
4. (Opsional) Gunakan fitur **Cetak DNS (PDF)** untuk menyimpan dokumen nilai sementara.

<Info>
 DNS bersifat *sementara*, nilai masih dapat berubah hingga proses validasi akhir selesai.
</Info>
