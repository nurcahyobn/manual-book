<Note>
  Anda dapat memperbarui data pribadi seperti email, nomor telepon, dan foto profil melalui halaman ini.
</Note>

## Cara Penggunaan

1. Pilih menu **Profile User**.
2. Sistem akan menampilkan halaman berisi informasi berita Utama dan Berita Kampus.
